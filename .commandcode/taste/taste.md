# Taste

## Communication
- Writes in Japanese and expects replies in Japanese. Confidence: 0.8
- When facing a large task, first asks for a rough, high-level overview of what needs to be done ("rough is fine") before drilling into details — answer with a concise step-by-step roadmap/digest rather than exhaustive depth. Confidence: 0.55

## Workflow
- Prefers a documentation-first, plan-driven workflow: before changing code, wants the task decomposed into detailed, step-by-step implementation procedures written to a Markdown file in the repository (e.g. a plan document that later serves as the basis for the rewrite). Confidence: 0.7
